# minimalist.lv

> **minimalist.lv** — Независимый, мультиязычный статический портал и база знаний, посвященная осознанному минимализму в жизни, физическом пространстве, цифровой среде и технологиях.

---

## 🌟 Ключевые особенности проекта

- **100% Static & Zero JS по умолчанию:** Сайт собран на Astro 5 в виде чистого, сверхбыстрого HTML+CSS без тяжелых фреймворков и лишних клиентских скриптов.
- **Мультиязычность (i18n):**
  - Базовый язык: **English (`en`)**
  - Обязательные языки: **Русский (`ru`)**, **Latviešu (`lv`)**
  - Корректная маршрутизация (`/en/`, `/ru/`, `/lv/`), теги `hreflang` и умные fallbacks.
- **Каталог софта в стиле Privacy Guides:** Каталог легкого, этичного софта (No-Bloat, Local-First, Open Source, Zero Telemetry) со строгими критериями отбора и вердиктами редакции.
- **База знаний и еженедельный блог:** Фундаментальные руководства и короткие 5-минутные статьи для регулярного чтения.
- **Встроенный локальный поиск (Pagefind):** Мгновенный поиск по контенту на этапе сборки без внешних серверов и трекинга.
- **Приватность по умолчанию:** 0 сторонних трекеров, 0 cookie-баннеров, 100/100 баллов по шкале Google Lighthouse.

## 🚀 Запуск в режиме разработки (Getting Started)

### Требования:
- **Node.js**: версия 18.17+ или 20+
- **Менеджер пакетов**: `npm` (или `pnpm` / `bun`)

### Шаги запуска:

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   # Клонирование репозитория
   git clone https://github.com/aleksejs1/minimalist.git
   cd minimalist
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер для разработки:**
   ```bash
   npm run dev
   ```
   Сайт будет доступен по адресу: `http://localhost:4321/`

4. **Сборка для продакшена (включая индекс Pagefind):**
   ```bash
   npm run build
   ```

5. **Предпросмотр собранного статического сайта:**
   ```bash
   npm run preview
   ```

---

## 📜 Доступные скрипты

- `npm run dev` — Запуск локального сервера разработки Astro с Hot Reload.
- `npm run build` — Полная статическая сборка сайта в папку `dist/` и построение индекса Pagefind.
- `npm run preview` — Локальный запуск production-сборки из папки `dist/`.
- `npm run lint` — Проверка синтаксиса Markdown и форматирования кода.
- `npm run i18n:check` — Проверка покрытия контента переводами на `en`, `ru` и `lv`.

---

## 🌍 Правила локализации (i18n)

Каждый контентный файл должен иметь точные копии структуры на всех трех поддерживаемых языках:
- Английский: `src/content/{collection}/en/{slug}.md`
- Русский: `src/content/{collection}/ru/{slug}.md`
- Латышский: `src/content/{collection}/lv/{slug}.md`

При добавлении нового термина или инструмента обязательно обновляйте словарь в `src/i18n/ui.ts`.
